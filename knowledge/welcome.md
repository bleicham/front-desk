# Welcome to the Front Desk

This is a sample document. Replace it with your own files.

## How this works

Any file you drop into the `knowledge/` folder becomes part of the Front Desk's
reference material. On every push, GitHub Actions re-reads the folder, rebuilds
the search index, and redeploys the site. Nothing else to do.

## Supported file types

The Front Desk can read Markdown (`.md`), plain text (`.txt`), PDF (`.pdf`),
Word documents (`.docx`), HTML, CSV, YAML, and JSON files. Files larger than
10 MB are skipped. You can organize files into subfolders — the folder
structure is preserved in source links.

## Getting started

Try asking the Front Desk: "What file types are supported?" or "How do I add
new documents?" — it should find this page and answer from it.
